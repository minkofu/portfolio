エサキホーム生活応援キャンペーン2025夏 LPサイト

#LPサイト　#コーディング　#デザイン制作

エサキホーム様の生活応援キャンペーン2025夏 LPサイトの制作に携わりました。

担当業務

デザイン制作 / コーディング / 納品

制作期間

デザイン〜コーディング：約3週間

制作ツール

Illustrator / Visual Studio Code

■PC版

■SP版

プロジェクト概要

以前から担当させていただいている、エサキホーム様のキャンペーンLPサイトの制作を担当しました。これまでも何度かLPサイトの制作を担当させていただいていますが、今回はデザインから携わらせていただきました。

意識したこと

⚫︎デザイン部分
先方から支給いただいたポスターを元に、タイトル周りは一部流用してデザインを制作しました。ポスターのイメージを活かしつつ、LPサイトとしての見やすさや、キャンペーンの内容が伝わりやすい構成を意識してデザインしました。

⚫︎コーディング部分
デザインに合わせて、HTML / CSS / JavaScriptを用いてコーディングを行いました。SP版は特に、スマホでの見やすさや使いやすさを意識して、レイアウトやボタンの大きさなど細部までこだわって制作しました。

成果

今まではコーディング作業がメインでしたが、今回はデザインから携わらせていただいたことで、サイト全体の構成やデザインの意図をより深く理解しながら制作することができました。先方からも、デザインやコーディングのクオリティを評価していただき、今後もLPサイトの制作を任せたいとお声がけいただきました。
