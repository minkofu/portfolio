イオン運命コスメLPサイト

#LPサイト　#コーディング　

イオン運命コスメ LPサイトの制作に携わりました。

担当業務

レギュレーション確認 / コーディング / 納品

制作期間

約1週間

制作ツール

Illustrator / Photoshop / Visual Studio Code

■PC版　※PC版はSP版流用し、広げた際に背景を固定する形で制作しました

■SP版

プロジェクト概要

新規LPサイトの制作案件で、コーディングを担当しました。先方から支給いただいたデザインを元に、HTML / CSS / JavaScriptを用いてコーディングを行いました。モバイルファーストのデザインだったため、SP版を先に制作し、PC版はSP版を流用して、広げた際に背景が固定される形で制作しました。

意識したこと

今回先方から事前にいただいていたレギュレーション資料があり、細かなルールに基づいてコーディングを行うことを意識しました。また、アニメーションに関しても一部指示いただき、希望通りの動きになるよう意識して制作することを心がけました。

成果

新規案件のLPサイト制作に携わらせていただきました。細かなルールに基づき制作することや、希望に沿った内容を取り入れて制作することで、お客様から信頼を得ることができました。その結果、この案件を機に再度LPサイト制作の依頼を受けることができ、私自身成長を実感することができました。
